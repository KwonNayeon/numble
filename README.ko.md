# 중소기업 폐업 예측 프로젝트

한국어 | [English](README.md)

## 프로젝트 개요

본 프로젝트는 기업경기실사지수(Business Trends and Outlook Survey) 데이터를 활용하여 중소기업의 폐업 여부를 예측하는 프로젝트입니다. 주요 내용은 다음과 같습니다:

- **데이터:** 설문조사 데이터를 기반으로 중소기업 폐업을 분석 및 예측
- **머신러닝 모델:** R을 활용하여 `randomForest`, `catboost`, `BART` 등의 패키지로 모델 구현
- **성능 평가:** AUROC, F1 score, accuracy 등의 지표로 모델 성능 평가
- **주요 발견:** 정확한 폐업 예측을 위해서는 비재무 데이터를 포함하는 것이 중요함을 확인

## 주요 결과

| 방법 | AUROC | F1 score | Accuracy |
|---|---|---|---|
| 베이스라인 | **0.556** | 0.964 | 0.940 |
| RF+ | 0.511 | 0.991 | 0.985 |
| CatBoost | 0.504 | **0.992** | **0.987** |
| BART | 0.536 | 0.977 | 0.961 |

- F1/Accuracy만 보면 CatBoost가 가장 우수했지만, AUROC는 오히려 베이스라인이 가장 높게 나타남
- 이는 클래스 불균형(폐업 기업 수 << 정상 기업 수)으로 인해 accuracy/F1이 소수 클래스 예측력을 충분히 반영하지 못하기 때문으로 판단됨
- 따라서 단일 지표가 아닌 AUROC·F1·Accuracy를 함께 비교하며 모델을 평가함
- 비재무 데이터를 추가로 포함했을 때 예측 성능이 개선됨을 확인함
